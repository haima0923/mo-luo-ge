自动化界面检查是可选的开发依赖：

```bash
npm install --no-save playwright
npx playwright install chromium
node scripts/ui-check.mjs
```

检查会新增一份明确标为演示的客户，不会删除任何真实客户。实际模型测试应另选经许可的业务样本，逐条校对识别和回复。
